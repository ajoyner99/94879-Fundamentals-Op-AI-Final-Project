# 94-879 Track B: Running Is Not the Same as Working

Team: Lauren Johnson, Anastasiya Joyner, Stephen Mai, Vidhi Kothari

This repository holds our Track B work on the course's real-time crypto-volatility service
(replay -> Kafka -> featurizer -> scorer API -> monitoring). We diagnosed and fixed three
operational failures: B1 Falling Behind, B2 Green but Broken, and B3 Healthy but Wrong?
The full write-up is our Technical Operationalization Brief, submitted on Canvas.
Setup instructions are in `STARTER_KIT_README.md`; each challenge README lists its own commands.
